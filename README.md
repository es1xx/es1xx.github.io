# Es1xx — портфоліо та демо

Статичний сайт: HTML, CSS, JavaScript. Без бекенду. На головній — Three.js, GSAP / ScrollTrigger і Lenis; на телефонах WebGL замінюється статичним WebP. Шрифти й оптимізовані фото WebP збережені локально.

## Запуск

```sh
python3 -m http.server 8081
```

Відкрити http://localhost:8081/. Встановлення залежностей для перегляду не потрібне.

## Сторінки

- `index.html` — портфоліо Es1xx.
- `barbershop/` — BLACKLINE.
- `cafe/` — Lume.
- `cafe/menu/` — QR-меню з пошуком.
- `autoservice/` — TORQUE.

## Публікація

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). Файл `.nojekyll` уже додано. Шляхи до локальних сторінок і ресурсів відносні. У 404 використано повне посилання на головну, яке працює також із вкладених невідомих адрес.

## Редагування

Кольори та шрифти визначені змінними в CSS. Кожен сайт має власний файл стилів. `assets/foundation.css` містить локальні шрифти й базові правила доступності. `assets/demo.js` керує вкладками, пошуком, порівнянням фото та умовною мобільною панеллю.

Особисті контакти Es1xx є лише на головній. Бізнеси, майстри, відгуки, показники та адреси в демо вигадані. Контакти демонстраційні; замінюються в HTML та атрибуті `data-telegram` форми. Форми лише відкривають Telegram з текстом і нічого автоматично не надсилають.

Фото: Unsplash, локальні оптимізовані копії. Порівняння «до/після» ілюстративне, з різними автомобілями. Карти показують умовну демолокацію в Черкасах із посиланням на OpenStreetMap.

Перед публікацією перевірити 390 / 768 / 1440 px, вкладки, пошук, клавіатурний фокус, форми та режим зменшення руху. Lighthouse запускати через HTTP окремо від браузерних тестів.
