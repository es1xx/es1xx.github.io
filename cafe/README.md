# Lume — демо-концепт від Es1xx

Статичні сторінки: `index.html` та `menu/index.html`. У меню 21 позиція — усі страви й напої з погодженого переліку. Дані, рецепти, відгуки, адреса та контакти вигадані.

## Перегляд

З кореня репозиторію:

```sh
python3 -m http.server 8081
```

Відкрити `http://localhost:8081/cafe/` або `http://localhost:8081/cafe/menu/`.

## QR-код

Адреса для коду: **https://es1xx.github.io/cafe/menu/**. Готовий файл для друку: [lume-menu-qr.svg](../assets/cafe/lume-menu-qr.svg).

Щоб згенерувати його знову, встановіть `qrencode` та виконайте з кореня репозиторію:

```sh
qrencode -t SVG -l M -m 4 -o assets/cafe/lume-menu-qr.svg 'https://es1xx.github.io/cafe/menu/'
```

Альтернатива — будь-який генератор статичних QR-кодів: вставте повну адресу вище й збережіть SVG. Використовуйте пряме посилання на меню, без проміжного сервісу. Після друку перевірте код камерою телефона; залиште світле поле навколо коду й не обрізайте його.

## Фото та ілюстрації

Кожна позиція має власний файл у `assets/cafe/menu/`: WebP, довша сторона 600 px, до 80 КБ. Одне фото однієї страви спільне для двох версій меню. Hero, шість кадрів галереї та обкладинка Open Graph не використовують фото страв із меню.

Точних відповідних фото не знайшлося для пʼяти позицій, тому вони мають окремі editorial-ілюстрації:

- `raf-coffee.webp` — раф;
- `banana-oatmeal.webp` — вівсянка з карамелізованим бананом;
- `pumpkin-risotto.webp` — різото з гарбузом та пармезаном;
- `sous-vide-chicken.webp` — курка су-від з картопляним пюре;
- `beet-salad.webp` — салат з печеним буряком і козячим сиром.

Поруч збережені редаговані SVG-оригінали. Для заміни підготуйте унікальне фото 600 px до 80 КБ й збережіть під тією ж назвою `.webp`. У відповідному рядку HTML на обох сторінках приберіть `.illustration-label`, змініть `data-illustration` на `false` та оновіть alt. Початкові зображення взяті з Unsplash; перелік джерел — [media-sources.json](../assets/cafe/media-sources.json).

## Стилі

Редагований файл — `assets/lume.css`, у HTML підключено `assets/lume.min.css`. Після зміни стилів оновіть мінімізовану копію з кореня репозиторію:

```sh
npx esbuild assets/lume.css --minify --outfile=assets/lume.min.css
```

## Взаємодії та контакти

`assets/lume.js` керує scrollspy, фільтрами на QR-сторінці, легким native dialog і мобільною панеллю. Страви й ціни доступні навіть без JavaScript. Модал закривається хрестиком, Esc, кліком поза ним або свайпом по зображенню; фокус повертається до страви.

Форма лише відкриває `@lume_demo` у Telegram із підготовленим текстом. Автоматичного надсилання й реального бронювання немає. Телефон `+380000000000` — плейсхолдер. OpenStreetMap завантажується лише після натискання кнопки карти; початкова схема показує умовну демолокацію в Черкасах.
